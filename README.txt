NOVA - Android voice assistant
1. Install Android Studio (developer.android.com/studio).
2. File > Open > choose this "Nova" folder. Wait for Gradle sync to finish (accept any "upgrade" prompt).
3. Build > Build Bundle(s) / APK(s) > Build APK(s). Click "locate" to find app-debug.apk.
   Or plug in your phone (USB debugging on) and press the green Run button.
4. Copy the APK to your phone and install it (allow "install unknown apps").
5. Open Nova > tap "Allow Display over other apps" > turn it on > go back > tap "Start Nova" > allow all permissions.
6. Say: "Nova, open Instagram", "Nova, call Amma", "Nova, play Anirudh on Spotify".
Tip: Settings > Apps > Nova > Battery > Unrestricted, so Android does not stop it.

NO ANDROID STUDIO? Build the APK online for free with GitHub:
1. Make a free account at github.com and create a new repository named Nova.
2. Upload ALL files from this folder (including the hidden .github folder) to it.
3. Open the "Actions" tab > "Build Nova APK" > wait ~5 minutes for the green tick.
4. Click the finished run > Artifacts > download "Nova-APK". Unzip it to get app-debug.apk and install it on your phone.
